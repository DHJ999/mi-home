# 米家看家

在自己电脑上登录小米账号，看家里米家摄像头的实时画面。**人在外面也能看**，不要求和摄像头同一局域网。

画面链路：小米云端加密 P2P 通道 → 本机流媒体服务打洞取流 → ffmpeg 转成浏览器能播的格式 → 网页播放。全程只经过这台电脑，不上传到任何第三方服务器。

## 快速开始

```bash
cd app
npm install
启动米家看家.cmd        # 或 node server.mjs
```

浏览器自动打开 <http://127.0.0.1:1990>，点「打开小米官方登录窗口」，在**小米自己的页面**里完成账号密码 / 短信 / 异地验证，登录结果会自动回到本页面。之后在设备列表点「观看」即可。

详细操作和排障见 [使用说明.md](使用说明.md)。

## 运行前提

| 依赖 | 说明 |
|---|---|
| Node.js 18+ | 后端与网页服务 |
| ffmpeg | 默认取 `D:\ffmpeg\bin\ffmpeg.exe`，改路径在 `app/go2rtc.mjs` 顶部 |
| `go2rtc/go2rtc-cs2.exe` | **不入库**，见下 |

## 目录

```
app/        网页 + Node 服务
  server.mjs        HTTP 接口与页面路由
  go2rtc.mjs        启停本机流媒体服务、注册摄像头、探流
  browser-login.mjs 用本机 Edge 真窗口完成小米登录并取回凭证
  public/           前端页面
go2rtc/     流媒体服务的可执行文件与运行时产物（配置/日志，均不入库）
```

## 本机端口

| 端口 | 用途 |
|---|---|
| 1990 | 网页界面与接口 |
| 1984 | 流媒体服务 API（仅 127.0.0.1，并做了来源白名单校验） |
| 8554 / 8555 | 本机 RTSP / WebRTC 转发 |

## 凭证与安全

- 小米登录态写在 `app/session.json`，流媒体账号凭证写在 `go2rtc/go2rtc-app.yaml`，**两者都在 `.gitignore` 里，不会进仓库**
- 密码只在登录时由用户自己输入，程序不记录明文
- 退出登录会删除 `session.json` 并停掉本机流媒体服务
- 不要把这两个文件发给任何人，拿到等于拿到你的小米账号

## 为什么仓库 clone 下来跑不了

米家摄像头的云端拉流协议（中继地址解码、握手报文）是我逆向出来的，成果编在 `go2rtc-cs2.exe` 里，属于逆向资料，**不随仓库发布**，所以这个仓库只有应用层代码。协议细节、支持的机型和踩坑记录都留在本地笔记里，不在这里公开。

## 已知边界

- 双摄机型目前只接了第一路镜头
- 首次建链约 5～20 秒（要等摄像头被唤醒并完成打洞）
- 海外账号需要设置环境变量 `MI_REGION`（默认 `cn`）指向对应分区
